# DSA

<ins>What was the problem you were solving in the projects for this course?</ins>  
In this course, I was creating an application that would access a users file of course information to provide them with sample schedules as well as printing course name, number, and prerequisites of specified courses.  
<ins>How did you approach the problem? Consider why data structures are important to understand.</ins>  
Initially I approached the problem by gaining an understanding of vectors, hash tables, and binary trees.  I decided to use hashtables for the code because it would provide the user with the most efficient option in my opinion.  
<ins>How did you overcome any roadblocks you encountered while going through the activities or project?</ins>  
I initially built the code using hash tables, but was running into compile problems.  I ended up switching back over to vectors as it was what I was much more familiar with.  I still plan on implementing hash tables more, but I was already running late with the project when I decided to change so I didn't cause more issues with this week's work in other classes.  
<ins>How has your work on this project expanded your approach to designing software and developing programs?</ins>  
I realize now that preplanning is very important, and creating a psuedocode that is a bit more in-depth than what I have been working through is necessary.  Because psuedocode is agnostic, I was trying to eliminate the need to use specific terms and generalized the code a bit too much.  Creating more granular psuedocode will benefit me in the future, especially when writing hash tables.  
<ins>How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?</ins>  
I now understand the need to pre-plan much more, and I have started using this with my own work as well.  While my job doesn't implement coding within it's needs, I have found ways to use it effectively.  I have started including more planning and modularization to make specific parts of radio programming reusable for my coworker that works with smaller public safety agencies, but needs to duplicate the work multiple times.
